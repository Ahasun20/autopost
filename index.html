  2. Graph API Explorer → তোমার Page select → pages_manage_posts, pages_read_engagement permission
  3. Generate Access Token → সেটা নিচে Page Access Token এ পেস্ট করো
  4. Page ID: 61581031296082 (তোমার Page ID auto বসানো আছে)
