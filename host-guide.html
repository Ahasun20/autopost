Render.com — সবচেয়ে সহজ (Recommended)
Free Web Service — 5 মিনিটে Done
FREE
  1. GitHub এ Push করো:
    তোমার fb-auto-poster ফোল্ডারটা GitHub এ push করো (private repo হলেও চলবে)।
  2. dashboard.render.com এ যাও → New + → Web Service → GitHub repo connect
  3. Settings:
    Build Command: npm install
    Start Command: npm start
    Plan: Free
    Region: Singapore (কাছাকাছি)
  4. Environment Variables (Add):
    PAGE_TOKEN = তোমার FB Page Access Token (EAAG...)
    CODECRAFT_KEY = তোমার codecraftapi.com API Key
    CODECRAFT_MODEL = gpt-4o-mini (optional)
    RUN_ON_START = 1 (optional — deploy এর 5 sec পর 1টা test post)
    Token/Key কখনো GitHub এ push করো না — শুধু Render Dashboard এ দাও।
  5. Deploy চাপো → 2-3 মিনিটে Live!
    Live URL পাবে: https://movie-autopilot-xxxx.onrender.com
  6. Test: https://YOUR-APP.onrender.com/run → সাথে সাথে 1টা Topic-matched ছবি সহ পোস্ট হবে!
Render Free Note: 15 মিনিট কোনো request না এলে Sleep যায় — কিন্তু Cron ভিতরে আছে তাই 6 ঘন্টা পর নিজে জেগে পোস্ট করবে। Sleep ঠেকাতে UptimeRobot.com (ফ্রি) দিয়ে 5 মিনিট পর পর / ping করো।
B
GitHub Actions — কোড ছাড়াই
Cron দিয়ে পোস্ট — কোনো সার্ভার লাগে না
FREE
  1. GitHub repo → Settings → Secrets and variables → Actions → New repository secret
    PAGE_TOKEN, CODECRAFT_KEY, PAGE_ID (=61581031296082)
  2. Repo তে ফাইল বানাও: .github/workflows/autopilot.yml — নিচের কোড পেস্ট করো → Push করো। প্রতি 6 ঘন্টায় auto চলবে।
name: Movie Autopilot
on:
  schedule:
    - cron: '0 */6 * * *'  # every 6 hours
  workflow_dispatch:
jobs:
  post:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: npm install
        working-directory: fb-auto-poster
      - run: node server.js
        working-directory: fb-auto-poster
        env:
          PAGE_TOKEN: ${{ secrets.PAGE_TOKEN }}
          CODECRAFT_KEY: ${{ secrets.CODECRAFT_KEY }}
          PAGE_ID: ${{ secrets.PAGE_ID }}
          RUN_ON_START: '1'
